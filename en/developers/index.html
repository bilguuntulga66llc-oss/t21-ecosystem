Build with T21

The T21 API and its Python client give access to T21's financial data.

  1. Sign in to the Developer Platform with GitHub and request access.
  2. Once T21 grants access, create a project. Its credential is created with it, and its secret is shown once.
  3. Exchange the credential for an access token and call the T21 API.

The concepts behind the data are in English; the full documentation is in Mongolian.
