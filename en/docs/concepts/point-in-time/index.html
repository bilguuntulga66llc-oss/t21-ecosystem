Point-in-time

Financial data carries more than one time: the period a figure reports, the date it was published, and the time T21 observed it. T21 stores each separately and serves each through its own parameter.

Time parameters

ParameterWhereMeaning
as_ofGET /v1/data/prices/{symbol}, GET /v1/market/candles/{symbol}The last trading day to include, inclusive. It filters the series as it is stored now, by day.
published_byFinancial statementsFilters statements by their publication date.
observed_byEndpoints built on stored observationsLimits the answer to what T21 had observed and stored by that time.

Each parameter has its own meaning on each endpoint. The endpoint's description in the API reference states it.

Time fields in a response

  • captured_at, observed_at: when T21 observed the source.
  • first_observed_at: when that content was first observed.
  • published_date: the statement's publication date.
  • period_end: the end of the reporting period.
  • generated_at: when the response was generated.

Valuation history

GET /v1/intelligence/{symbol}/valuation-history calculates each day's measures from the statements published before that trading day.

Corrections and history

When the exchange later corrects or withdraws a trading day's data, T21 keeps both the original and the corrected observation.
