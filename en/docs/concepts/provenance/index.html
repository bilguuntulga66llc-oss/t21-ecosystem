Provenance

Provenance states where a figure came from: which source, which file, when, and by which reading.

Observations

Each observation of a source records its status, observed_at, run_id and, when it succeeds, its content_sha256. Each distinct content is stored with its first_observed_at.

Financial statements

FieldMeaning
file_sha256SHA-256 hash of the source file
capture_sha256SHA-256 hash of the table reading
items_sha256SHA-256 hash of the extracted figures
reader_versionThe version of the reading
cells.{figure}sheet, cell, stated, unit_mnt, unit_from

Source registry

GET /v1/system/source-registry lists the sources T21 reads, with their key, aliases and capture family. It needs no credential.

Provenance fields depend on the kind of data. Each payload's schema is in the API reference.
