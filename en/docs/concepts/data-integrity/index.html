Data integrity

Data integrity is the set of mechanisms that check that stored data has not changed, that history has not been overwritten, and that a statement's figures agree with each other.

Mechanisms

MechanismWhat it checksStatus
Storage checkChecks stored content by its hash and refuses damaged data.Production
Append-only price observationsKeeps exchange corrections and withdrawals without deleting anything.Production
ReconciliationChecks that a statement's figures agree, with the unit and the difference: agrees, agrees_at_scale, differs, record_states_zero.Production

Reconciliation is served by GET /v1/intelligence/{symbol}/reconciliation. When conflicting statements share the same time, it returns the error ambiguous_capture_selection.
