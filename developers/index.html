T21 ашиглан хөгжүүлэх

T21 Foundation-ий санхүүгийн өгөгдөлд Developer Platform-оос авсан хандалтын эрхээр REST API эсвэл Python SDK ашиглан хандана. Өгөгдлийн хүрээ, хүсэлтийн хэлбэрийг API баримт бичгээс үзнэ үү. T21-ийн тухай →

    GitHub-ээр нэвтрэх

    Developer Platform-д GitHub бүртгэлээрээ нэвтэрнэ үү.

    Developer Platform нээх ↗
  2. 02

    Төсөл үүсгэх

    Төслийн нэрээ оруулаад «Create project + credential» товчийг дарна уу.

  3. 03

    API хандалтын эрх үүсгэх

    Төсөлтэй хамт API хандалтын эрх үүснэ. Хандалтын түлхүүр зөвхөн нэг удаа харагдах тул хуулж, аюулгүй газар хадгална уу.

  4. 04

    API ашиглах

    REST API эсвэл Python SDK ашиглана уу. Хандалтын түлхүүрийг зөвхөн сервер талд хадгална уу.
