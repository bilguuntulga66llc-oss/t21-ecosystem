T21 экосистем

T21 нь санхүүгийн өгөгдлийн дэд бүтэц. T21 Foundation нь өгөгдлийг цуглуулан боловсруулж, T21 Developer Platform нь хөгжүүлэгчдэд API хандалт олгодог.

Хаанаас эхлэх

  • T21-ийн тухай

    Зорилго, технологи, бүтэц.

  • Хөгжүүлэгчдэд

    Developer Platform, API reference, Python client.

  • Баримт бичиг

    Get started, Concepts, Access, Data catalog.
