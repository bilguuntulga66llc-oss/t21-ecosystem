T21 экосистем

T21 нь Монголын санхүүгийн өгөгдлийн дэд бүтэц. T21 Foundation нь өгөгдлийг цуглуулан боловсруулж, T21 Developer Platform нь хөгжүүлэгчдэд API хандалт олгодог.

Энэ сайтад T21 экосистемийн бүтээгдэхүүнүүд, T21 ашиглан хөгжүүлэх баримт бичиг, хэрэгсэл багтана.

Хаанаас эхлэх

  • T21-ийн тухай

    Зорилго, өгөгдөл, бүрэлдэхүүн хэсгүүд.

  • Бүтээгдэхүүнүүд

    MMI, Capital Atlas.

  • Хөгжүүлэгчдэд

    Developer Platform, API баримт бичиг, Python SDK.
