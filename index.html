T21 экосистем

T21 бол Монголын санхүүгийн өгөгдөл хэрэгтэй хөгжүүлэгч, судлаач, байгууллагуудад зориулсан санхүүгийн өгөгдлийн платформ. T21 Foundation нь өгөгдлийг цуглуулан боловсруулж, T21 Developer Platform нь хөгжүүлэгчдэд API хандалт олгодог.

Хаанаас эхлэх

  • T21-ийн тухай

    Зорилго, технологи, бүтэц.

  • Өгөгдөл

    Хөрөнгийн зах зээл, компанийн мэдээлэл, макро эдийн засаг.

  • Хөгжүүлэгчдэд

    Developer Platform, API reference, Python client.

  • Баримт бичиг

    Get started, Guides, Concepts, Access, Data catalog.
