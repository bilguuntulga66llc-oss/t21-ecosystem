    Баримт бичиг / Concepts / Data contracts

    Data contracts

    Production

    T21-ийн хариу бүр хувилбартай envelope болон domain schema-тай. Contract өөрчлөгдөхдөө нийцлийн бодлогыг баримтална.

    REST хариуны envelope

    ТалбарУтга
    api_schema_versionAPI contract-ийн хувилбар (api.v2.0.0)
    sdk_schema_versionSDK contract-ийн хувилбар (sdk.v2.0.0)
    output_schema_versionГаралтын schema-ийн хувилбар (1.7.0)
    generated_atХариу үүссэн хугацаа
    request_idХүсэлтийн таних тэмдэг. Асуудал мэдэгдэхэд хэрэглэнэ.
    source, endpoint, paramsХариуны гарал, endpoint, параметрүүд
    dataDomain payload

    Domain payload бүр өөрийн schema-тай, жишээ нь valuation_history.v1, listed_identity.v1. MCP-ийн үр дүн болон Developer Platform-ийн token хариу өөр хэлбэртэй.

    Хувилбар

    REST route нь /v1/ дор байна. T21 API 2.1.0, Developer Platform 0.2.0 хувилбартай.

    Нийцлийн бодлого

    • Хүчин төгөлдөр contract-д одоогийн утга, бүтцийг алдагдуулахгүйгээр шинэ талбар нэмж болно.
    • Breaking change хийхэд major хувилбарыг ахиулж, шилжих хугацаа, орлох contract, шилжих заавар, changelog-ийг нийтэлнэ.
    • Хуучирсан alias нь орлох route болон хасагдах хувилбарыг header-ээр мэдэгдэнэ.
