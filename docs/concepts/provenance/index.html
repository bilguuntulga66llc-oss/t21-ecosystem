Provenance

Provenance нь үзүүлэлт хаанаас, ямар файлаас, хэзээ, ямар уншилтаар гарсныг заана.

Ажиглалт

Эх сурвалжийн ажиглалт бүр status, observed_at, run_id, амжилттай бол content_sha256-ийг бүртгэнэ. Ялгаатай агуулга бүр first_observed_at-тай хадгалагдана.

Санхүүгийн тайлан

ТалбарУтга
file_sha256Эх файлын SHA-256 hash
capture_sha256Хүснэгтийн уншилтын SHA-256 hash
items_sha256Гаргаж авсан үзүүлэлтүүдийн SHA-256 hash
reader_versionУншилтын хувилбар
cells.{figure}sheet, cell, stated, unit_mnt, unit_from

Эх сурвалжийн бүртгэл

GET /v1/system/source-registry нь T21-ийн уншдаг эх сурвалжуудыг key, alias, capture family-тай нь жагсаана. Credential шаардахгүй.

Provenance-ийн талбарууд өгөгдлийн төрлөөс хамаарна. Payload бүрийн schema-г API reference-ээс үзнэ.
