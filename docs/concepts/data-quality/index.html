Data Quality

T21 Data Quality-г өгөгдөлтэй хамт төлөв хэлбэрээр хүргэнэ. Дутуу, зөрүүтэй, тодорхойгүй мэдээлэл тус бүр өөрийн төлөвтэй ирнэ.

Үнийн мөрийн төлөв

ТөлөвУтга
passМөрийн шалгалт давсан.
no_tradeТухайн өдөр арилжаа болоогүй. Арилжааны хэмжээ 0 байх нь энэ төлөвийг илэрхийлж болно.
review_requiredШалгах шаардлагатай, жишээ нь арилжаа болсон өдрийн тэг үнэ.
unmeasuredТүүх хоосон, хэмжилт хийгдээгүй.

Дутуу ба тэг

  • Хоосон жагсаалт, хэзээ ч ажиглагдаагүй өгөгдөл (never_captured), эх сурвалжийн алдаа (source_error), уншилтаар хасагдсан өгөгдөл тус бүр тусдаа төлөвтэй.
  • Тайланд бодитоор 0 гэж бичигдсэн утга stated: 0 хэлбэрээр ирнэ. Уншиж чадаагүй нүд checks.unreadable_items-д бүртгэгдэнэ.
  • Нэгж тодорхойгүй үед (units_withheld) холбогдох мөнгөн дүн null байна.
