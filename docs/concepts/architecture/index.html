Architecture

T21 нь санхүүгийн өгөгдлийг хариуцдаг T21 Foundation болон хандалтыг хариуцдаг Developer Platform гэсэн хоёр үйлчилгээнээс бүрдэнэ. Production орчин single-node deployment-ээр ажилладаг.

Хэрэгжсэн бүрэлдэхүүн

БүрэлдэхүүнҮүрэгТөлөв
Developer PlatformGitHub-ээр нэвтрэлт, project, credential. Credential-ийг token-оор солих POST /v1/token, баталгаажуулах түлхүүр ба revocation snapshot нийтэлнэ. Python client түгээнэ.Production

Trust boundary

Token-ийг Developer Platform олгоно. T21 Foundation түүнийг өөрөө баталгаажуулна: гарын үсэг, iss, aud, хүчинтэй хугацаа, revocation төлөв, тухайн operation-д олгосон scope. Credential цуцлагдвал шинэ token олгохоо даруй зогсооно. Өмнө олгогдсон token-ийг Foundation ихэвчлэн 30 секунд тутам шинэчлэгддэг revocation snapshot-ийг үндэслэн хүчингүйд тооцно. Snapshot байхгүй эсвэл хугацаа нь дууссан бол хүсэлтээс татгалзана.

Зарчим

Санхүүгийн утга, түүх, тооцоолол Foundation-д; хандалт, project, хэрэглээ Platform-д; бизнесийн логик хэрэглээний бүтээгдэхүүнд үлдэнэ. Нэг санхүүгийн объект бүх хэрэглэгчид ижил таних тэмдэг, хугацааны утга, contract-тай хүрнэ.

Төлөвлөсөн

  • Хэрэглээний бүртгэлийг Platform-д хүргэх, quota болон төлбөрийн тооцоо
  • Гадны байгууллагын бодит хэрэглээгээр баталгаажсан экосистемийн түвшин
