    Architecture

    T21 нь санхүүгийн өгөгдлийг хариуцдаг T21 Foundation болон хандалтыг хариуцдаг Developer Platform гэсэн хоёр үйлчилгээнээс бүрдэнэ.

    Бүрэлдэхүүн

    БүрэлдэхүүнҮүрэгТөлөв
    Developer PlatformGitHub-ээр нэвтрүүлж, нээлттэй түвшний open:read болон T21-ийн зөвшөөрсөн scope-оор project, credential-ийг удирдана. Credential-ийг token-оор солих POST /v1/token, баталгаажуулах түлхүүр ба revocation snapshot нийтэлнэ. Python client түгээнэ.Production
    T21 APIСанхүүгийн эх сурвалжийг уншиж, ажиглалтыг хадгалж, REST-ээр хүргэнэ.Production
    T21 Foundation MCPAI агентад зориулсан MCP (SSE) үйлчилгээ. T21 API-тай ижил token-оор хандана.Production

    Trust boundary

    Token-ийг Developer Platform олгоно. T21 Foundation түүнийг өөрөө баталгаажуулна: гарын үсэг, iss, aud, хүчинтэй хугацаа, revocation төлөв, тухайн endpoint-д олгосон scope. Credential цуцлагдвал шинэ token олгохоо даруй зогсооно. Өмнө олгогдсон token-ийг T21 Foundation revocation snapshot-ийг үндэслэн хүчингүйд тооцно. Snapshot-ийг 30 секундэд нэгээс илүүгүй удаа шинэчилнэ. Snapshot байхгүй эсвэл хугацаа нь дууссан бол хүсэлтээс татгалзана.
