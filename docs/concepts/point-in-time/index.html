    Point-in-time

    Санхүүгийн өгөгдөлд тайлант үе, нийтлэгдсэн огноо, T21-ийн ажигласан хугацаа гэсэн ялгаатай хугацаанууд байдаг. T21 эдгээрийг тусад нь хадгалж, параметр бүрээр ялгаж хүргэнэ.

    Хугацааны параметрүүд

    ПараметрХаанаУтга
    as_ofGET /v1/data/prices/{symbol}, GET /v1/market/candles/{symbol}Арилжааны өдрийн дээд хязгаар (тухайн өдрийг багтаана). Одоо хадгалагдаж буй цувааг өдрөөр шүүнэ.
    published_byСанхүүгийн тайланТайлангийн нийтлэгдсэн огноогоор шүүнэ.
    observed_byХадгалсан ажиглалтад суурилсан endpointT21-ийн тухайн хугацаанд ажиглаж хадгалсан мэдээллээр хязгаарлана.

    Параметр бүр endpoint тус бүрт өөрийн утгатай. Тухайн endpoint-ийн тайлбарыг API reference-ээс үзнэ.

    Хариун дахь хугацааны талбарууд

    • captured_at, observed_at: T21 эх сурвалжаас ажигласан хугацаа.
    • first_observed_at: тухайн агуулгыг анх ажигласан хугацаа.
    • published_date: тайлангийн нийтлэгдсэн огноо.
    • period_end: тайлант үеийн эцэс.
    • generated_at: хариу үүссэн хугацаа.

    Үнэлгээний түүх

    GET /v1/intelligence/{symbol}/valuation-history өдөр бүрийн үзүүлэлтийг тухайн арилжааны өдрөөс өмнө нийтлэгдсэн тайлангаар тооцно.

    Засвар ба түүх

    Бирж арилжааны өдрийн мэдээллийг дараа нь засах эсвэл хүчингүй болгох үед T21 анхны болон засварласан ажиглалтыг хоёуланг нь хадгална.
