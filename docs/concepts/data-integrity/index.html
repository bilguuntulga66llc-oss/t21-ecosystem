    Data integrity

    Data integrity нь хадгалсан өгөгдөл өөрчлөгдөөгүй, түүх дарж бичигдээгүй, тайлангийн үзүүлэлтүүд хоорондоо нийцэж буйг шалгах механизмуудыг хэлнэ.

    Механизм

    МеханизмЮуг шалгадагТөлөв
    Хадгалалтын шалгалтХадгалсан агуулгыг hash-аар нь шалгаж, гэмтсэн өгөгдлийг хүлээн авахгүй.Production
    Append-only үнийн ажиглалтБиржийн засвар, хүчингүй болголтыг устгалгүй хадгална.Production
    ТулгалтТайлангийн үзүүлэлтүүдийн нийцлийг нэгж, зөрүүтэй нь шалгана: agrees, agrees_at_scale, differs, record_states_zero.Production

    Тулгалтыг GET /v1/intelligence/{symbol}/reconciliation-оос авна. Ижил хугацаатай зөрчилтэй тайлан байвал ambiguous_capture_selection алдаа буцаана.
