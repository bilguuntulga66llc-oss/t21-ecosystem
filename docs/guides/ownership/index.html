    Хувь эзэмшигчдийг авах

    Production

    Компанийн томоохон хувь эзэмшигчид, эзэмшлийн төвлөрлийг авна.

    Шаардлага

    knowledge:read scope-той token. Token авах алхмыг Get started-аас үзнэ.

    Python client

    from t21 import T21

client = T21()
response = client.ownership("APU", top_n=5)
data = response["data"]
print(data["top3_percent"], data["hhi"])

    HTTP

    curl "https://t21-api-production.up.railway.app/v1/intelligence/APU/ownership?top_n=5" \
  -H "Authorization: Bearer <access_token>"

    Параметр

    ПараметрУтга
    symbolҮнэт цаасны код, жишээ нь APU.
    top_nБуцаах хувь эзэмшигчийн тоо, 1–100. Анхдагч утга 10.
    storedtrue үед T21-ийн хадгалсан хувилбарыг уншина.
    observed_byОгноо, цаг. T21 тухайн мөч хүртэл хадгалсан хувилбар.

    Хариу

    • data.top_holders: хувь эзэмшигч бүр, provenance-той.
    • data.top_holder_percent, data.top3_percent, data.top5_percent, data.hhi: эзэмшлийн төвлөрөл.
    • data.captured_at: T21 эдгээр хувь эзэмшигчийг биржээс уншсан хугацаа.
    • data.withheld_holders: эзэмшлийн хувь нь 0–100-аас гадуур бичигдсэн хувь эзэмшигч. Ийм хувь эзэмшигч байвал төвлөрлийн үзүүлэлтүүд null байна.
