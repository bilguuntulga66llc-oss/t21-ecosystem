    Санхүүгийн тайлан авах

    Production

    Компанийн биржид мэдүүлсэн санхүүгийн тайланг мөр мөрөөр нь авна.

    Шаардлага

    knowledge:read scope-той token. Token авах алхмыг Get started-аас үзнэ.

    Python client

    from t21 import T21

client = T21()
response = client.financial_statements("APU", year=2024, season=4)
for row in response["data"]["rows"]:
    for statement in row["statements"]:
        print(statement["statement"], statement["unit"], len(statement["lines"]))

    HTTP

    curl "https://api.t21.one/v1/intelligence/APU/financial-statements?year=2024&season=4" \
  -H "Authorization: Bearer <access_token>"

    Параметр

    ПараметрУтга
    symbolҮнэт цаасны код, жишээ нь APU.
    yearТайлант жил.
    seasonУлирал, 1–4, биржийн дугаарласнаар.
    published_byISO 8601 огноо. Биржийн тухайн өдөр болон түүнээс өмнө нийтэлсэн тайлангуудыг буцаана.
    observed_byISO 8601 огноо, цаг. T21-ийн тухайн мөч хүртэл хадгалсан хувилбарыг буцаана.

    year, season-ийг өгөхгүй бол хамгийн сүүлд хадгалсан тайлан ирнэ.

    Хариу

    • data.filings: биржийн жагсаасан тайлан бүр, шинээс хуучин руу. year, season, published_date, audit_org, workbook_status.
    • data.rows: сонгосон тайлан. statements бүр statement (financial_position, income, changes_in_equity, cash_flow), unit, columns, lines-тэй.
    • data.unmeasured: хадгалагдаагүй эсвэл файлгүй тайлан, шалтгаантай нь.

    Баганын нэр, мөрийн шошго, нэгж тайланд бичигдсэн хэвээрээ ирнэ. Тайланд нэгжийг тодорхой бичээгүй бол unit_mnt нь null байна. Эх файлын SHA-256 hash болон бусад гарал үүслийн талбарыг Provenance-аас үзнэ.
