    Ханшийн түүх авах

    Production

    Нэг үнэт цаасны арилжааны өдрийн ханшийг огноогоор нь авна.

    Шаардлага

    market:read scope-той token. Token авах алхмыг Get started-аас үзнэ.

    Python client

    from t21 import T21

client = T21()
response = client.prices("APU", limit=100)
for bar in response["data"]["history"]:
    print(bar["date"], bar["close_price"])

    HTTP

    curl "https://api.t21.one/v1/data/prices/APU?limit=100" \
  -H "Authorization: Bearer <access_token>"

    Параметр

    ПараметрУтга
    symbolҮнэт цаасны код, жишээ нь APU.
    limitБуцаах өдрийн тоо, 1–1000. Анхдагч утга 30.
    as_ofОгноо, YYYY-MM-DD. Энэ өдөр болон түүнээс өмнөх өдрүүд ирнэ.

    Хариу

    • data.security: үнэт цаасны symbol, name.
    • data.history: өдөр бүрийн date, close_price болон quality.
    • data.total: буцаасан өдрийн тоо.

    Тодорхой өдөр хүртэлх түүх

    response = client.prices("APU", as_of="2025-12-31", limit=250)

    Огнооны утга буруу бол HTTP 400 буцаана. as_of хэрхэн ажилладгийг Point-in-time-аас үзнэ.
