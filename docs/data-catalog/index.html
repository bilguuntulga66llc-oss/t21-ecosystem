Data catalog

T21-ийн хүргэдэг өгөгдлийг төрлөөр нь жагсаав. Endpoint бүрийн параметр, хариуг API reference-ээс үзнэ.

ӨгөгдөлEndpointScopeТөлөв
Үнэт цаасны жагсаалт, дэлгэрэнгүй/v1/data/company:readProduction
Ханшийн түүх, статистикGET /v1/data/prices/{symbol}, GET /v1/data/statsmarket:readProduction
Зах зээл: индекс, зах зээлийн үнэлгээ, арилжаа, candles, ногдол ашиг, мэдэгдэл/v1/market/market:read, disclosures:readProduction
Компани: профайл, хувь эзэмшил, засаглал, санхүүгийн тайлан, суурь үзүүлэлт, үнэлгээ/v1/intelligence/company:read, knowledge:readProduction

Судалгаа: feature, label, dataset/v1/research/datasets:readExperimental

Хамрах хугацаа

  • Арилжааны өдрийн ханш 1999-12-09-өөс; арилжааны тоо, VWAP 2012-07-02-оос. Хамрах хүрээ үнэт цаас бүрт өөр.
  • Санхүүгийн тайлан 2013 оноос, зарим тайлан дутуу эсвэл хэсэгчлэн уншигдсан.
  • Ногдол ашгийн бүртгэл 2015 оноос.
  • Макро статистикийн хүснэгт бүрийн хамрах хугацаа харилцан адилгүй.

Одоогийн эх сурвалж: Монголын хөрөнгийн бирж (MSE), Үндэсний статистикийн хороо (NSO). Хадгалсан өгөгдлийн хэмжээ census-ээр хэмжигдэнэ.
