    Баримт бичиг / Access

    Access

    T21 API-д Developer Platform-ийн олгосон token-оор хандана. Token-ий scope нь хандах endpoint-ийг тодорхойлно.

    Authentication

    Credential secret-ийг POST /v1/token-д илгээж token авна. scopes жагсаалт өгвөл token-ий scope-ийг нарийсгана. Token 300 секунд хүчинтэй.

    Credential үүсгэх, token авах бүрд Developer Platform T21-ийн зөвшөөрлийг шалгана. T21-ийн зөвшөөрөөгүй scope-той credential үүсгэвэл HTTP 403, scope_not_grantable алдаа буцаана. Зөвшөөрлийг цуцалбал тухайн scope-той credential цуцлагдана.

    T21 API-д token-ийг Authorization: Bearer <access_token> эсвэл x-api-key header-ээр илгээнэ. Хоёуланг нь илгээвэл x-api-key-г ашиглана.

    Token нь t21_access.v1 contract бүхий PASETO v4.public (Ed25519). Claim: iss, aud, sub, project_ref, credential_ref, jti, iat, nbf, exp, scopes.

    Scope

    ScopeХамрах өгөгдөл
    market:readХанш, арилжаа, макро статистик, зах зээлийн статистик
    company:readҮнэт цаасны жагсаалт, дэлгэрэнгүй, компанийн танилцуулга
    disclosures:readМэдэгдэл, үнэт цаас гаргагчийн нийтэлсэн мэдээлэл, компанийн үйл явдал
    knowledge:readСанхүүгийн тайлан, хувь эзэмшил, засаглал, суурь үзүүлэлт, үнэлгээ, өгөгдлийн бүрэн бүтэн байдал
    datasets:readСудалгааны каталог, dataset-ийн хайлт, шалгалт

    Хамгаалагдсан endpoint бүр нэг scope шаардана.

    Credential шаардахгүй endpoint

    GET /v1/system/health, GET /v1/system/consumption-manifest, GET /v1/system/source-registry, GET /v1/system/datasets.

    Rate limit

    Developer Platform-ийн token-оор илгээсэн хүсэлтэд project тус бүрээр rate limit үйлчилнэ. Rate limit хэтэрвэл 429 буцаана. Хүсэлтийн давтамжийг Retry-After болон X-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Reset header-ийн дагуу тохируулна. X-RateLimit-Reset нь хязгаар шинэчлэгдэх хүртэлх секунд.

    Developer Platform алдааг {"error": {"code": "…"}}, харин T21 API token-ий баталгаажуулалтын алдааг {"detail": {"code": "…"}} хэлбэрээр буцаана. Accept: application/problem+json header илгээвэл хоёр үйлчилгээ алдааг RFC 9457 Problem Details хэлбэрээр буцаана: type, title, status, detail, instance, code. T21 API-ийн хариуны request_id-г асуудал мэдэгдэхэд ашиглана.
