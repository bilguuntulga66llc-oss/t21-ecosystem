    Баримт бичиг / Get started

    Get started

    Энэ заавраар Developer Platform-д project үүсгэж, credential авч, T21 API-д анхны хүсэлтээ илгээнэ.

    Эхлэхийн өмнө

    Credential үүсгэхэд T21-ийн зөвшөөрөл шаардлагатай. Зөвшөөрлийг Developer Platform-д нэвтэрч хүснэ үү.

    1. Project болон credential үүсгэх

    Developer Platform-д project үүсгэнэ үү. Project үүсэхэд credential хамт үүснэ. Credential secret зөвхөн нэг удаа харагдана. Үүнийг орчны хувьсагчид хадгална уу.

    2. Python client ашиглах

    Python client-ийг татаж аваад credential secret-ээ орчны хувьсагчид тохируулна уу. Python 3.9 буюу түүнээс дээш хувилбар шаардана.

    curl -O https://t21-platform-production.up.railway.app/sdk/python/t21.py
export T21_CREDENTIAL="<credential secret>"
    from t21 import T21

client = T21()
print(client.stats()["data"])

    3. HTTP-ээр шууд хандах

    Credential secret-ийг POST /v1/token-д илгээж token авна уу. Token 300 секунд хүчинтэй.

    curl -X POST https://t21-platform-production.up.railway.app/v1/token \
  -H "Content-Type: application/json" \
  -d '{"credential_secret": "<credential secret>"}'

    Хариунд access_token, token_type (Bearer), expires_in, scopes талбарууд ирнэ. Token-ийг T21 API-д Authorization header-ээр илгээнэ үү.

    curl https://t21-api-production.up.railway.app/v1/data/stats \
  -H "Authorization: Bearer <access_token>"
