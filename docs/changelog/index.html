    Баримт бичиг / Reference / Changelog

    Changelog

    T21 API, Developer Platform, өгөгдөл болон баримт бичигт орсон, хэрэглэгчдэд хамаарах өөрчлөлтүүд.

    2026-11-22

    T21 API

    • OpenAPI-д x-t21-reads: stored_on_request гэж тэмдэглэсэн 13 endpoint stored=true эсвэл observed_by параметрээр T21-ийн хадгалсан хувилбарыг буцаана. Үүнд индекс, багцын арилжаа, хувь эзэмшил, засаглал, компанийн үйл явдал, мэдэгдэл орно.
    • OpenAPI нь Quantitative research-ээс бусад бүлгийн endpoint-ийн амжилттай хариуны schema-г тусгав.

    2026-11-21

    T21 API

    • GET /v1/risk/{symbol} нэмэгдэв: хувьцааны хуваалтад тохируулсан өдрийн ханшийн volatility, maximum drawdown, өгөөжийн outlier. Төлөв: Experimental.
    • GET /v1/system/datasets нэмэгдэв: T21-ийн нийлүүлдэг dataset-ийн каталог, DCAT 3 JSON-LD хэлбэрээр. Credential шаардахгүй.
    • OpenAPI-д endpoint бүр өгөгдлөө хэрхэн уншдагийг x-t21-reads, агуулгын түвшнийг x-t21-layer заана.
    • GET /v1/intelligence/{symbol} deprecated болов. API v3 хүртэл Deprecation болон Link header-тэй хариулна. Түүний хэсгүүдийг тус тусын endpoint буцаана.

    T21 API, Developer Platform

    • Accept: application/problem+json header илгээсэн хүсэлтийн алдааг RFC 9457 Problem Details хэлбэрээр буцаана.

    Баримт бичиг

    • Өгөгдөл хэсгийг T21-ийн dataset каталогаас бүтээв: есөн ангилал, dataset бүрийн хуудас.

    2026-11-20

    Developer Platform

    • OpenAPI нь POST /v1/token-ий хариу (access_token, token_type, expires_in, scopes), алдааны кодууд болон нэвтэрсэн browser session шаардлагатай endpoint-уудыг тусгав.

    Баримт бичиг

    • Техникийн баримт бичиг нийтлэгдэв: Get started, Concepts, Access, Data catalog.
    • Guides нэмэгдэв: ханшийн түүх, санхүүгийн тайлан, хувь эзэмшлийн мэдээлэл авах.
    • Баримт бичгээс хайх боломжтой болов.
    • Өгөгдөл хуудас нийтлэгдэв: өгөгдлийн төрөл бүрийн хамрах хүрээ, эх сурвалж, төлөв.

    2026-11-19

    T21 API

    • OpenAPI нь x-api-key-ийн зэрэгцээ Authorization: Bearer header-ийг тусгав.
    • OpenAPI-д endpoint бүрийн буцаах өгөгдлийг тайлбарлав.
